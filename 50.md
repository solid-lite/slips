SLIP-50
=======

ActivityPub
-----------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|

This SLIP defines ActivityPub integration for Fediverse federation.

## Overview

ActivityPub enables federation with the Fediverse (Mastodon, Pleroma, etc.). Users can follow, be followed, and exchange activities with millions of Fediverse users.

## Actor Endpoints

Every user has an Actor document with inbox/outbox:

```json
{
  "@context": "https://www.w3.org/ns/activitystreams",
  "type": "Person",
  "id": "https://example.com/alice",
  "inbox": "https://example.com/alice/inbox",
  "outbox": "https://example.com/alice/outbox",
  "followers": "https://example.com/alice/followers",
  "following": "https://example.com/alice/following",
  "preferredUsername": "alice",
  "name": "Alice",
  "publicKey": {
    "id": "https://example.com/alice#main-key",
    "owner": "https://example.com/alice",
    "publicKeyPem": "-----BEGIN PUBLIC KEY-----..."
  }
}
```

## Inbox

The inbox receives activities from other servers:

```http
POST /alice/inbox HTTP/1.1
Host: example.com
Content-Type: application/activity+json
Signature: keyId="...",algorithm="rsa-sha256",headers="...",signature="..."

{
  "@context": "https://www.w3.org/ns/activitystreams",
  "type": "Follow",
  "actor": "https://mastodon.social/users/bob",
  "object": "https://example.com/alice"
}
```

## Outbox

Activities are posted to the outbox:

```http
POST /alice/outbox HTTP/1.1
Host: example.com
Authorization: Bearer ...
Content-Type: application/activity+json

{
  "@context": "https://www.w3.org/ns/activitystreams",
  "type": "Create",
  "actor": "https://example.com/alice",
  "object": {
    "type": "Note",
    "content": "Hello Fediverse!"
  }
}
```

## Activity Types

| Type | Description |
|------|-------------|
| `Create` | Create a new object |
| `Update` | Modify existing object |
| `Delete` | Remove an object |
| `Follow` | Request to follow |
| `Accept` | Accept a request |
| `Announce` | Boost/share content |
| `Like` | Like content |

## WebID Integration

Solid WebID can be the ActivityPub Actor ID:

```json
{
  "@context": [
    "https://www.w3.org/ns/activitystreams",
    "https://w3id.org/webid"
  ],
  "type": "Person",
  "id": "https://example.com/alice/#me",
  "storage": "/",
  "inbox": "/alice/inbox",
  "outbox": "/alice/outbox"
}
```

## did:nostr + ActivityPub

Users can also use did:nostr identity:

```json
{
  "alsoKnownAs": ["did:nostr:f0af1228a863772c0661ca0dd2586c58668de52ca9f71973404e7b9b1f5edc4d"]
}
```
