SLIP-33
=======

PATCH Operations
----------------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | ✅ Yes |

This SLIP defines PATCH support for partial resource updates.

## Overview

PATCH allows modifying resources without replacing the entire content. Solid Lite supports N3 Patch and SPARQL Update formats.

## Content Types

| Format | Content-Type |
|--------|--------------|
| N3 Patch | `text/n3` |
| SPARQL Update | `application/sparql-update` |

## N3 Patch

N3 Patch uses `solid:inserts` and `solid:deletes`:

```
@prefix solid: <http://www.w3.org/ns/solid/terms#>.
@prefix foaf: <http://xmlns.com/foaf/0.1/>.

_:patch a solid:Patch;
  solid:deletes { <#me> foaf:name "Alice" };
  solid:inserts { <#me> foaf:name "Alicia" }.
```

## SPARQL Update

```sparql
PREFIX foaf: <http://xmlns.com/foaf/0.1/>

DELETE { <#me> foaf:name "Alice" }
INSERT { <#me> foaf:name "Alicia" }
WHERE { <#me> foaf:name "Alice" }
```

## Request

```http
PATCH /alice/profile HTTP/1.1
Content-Type: text/n3

@prefix solid: <http://www.w3.org/ns/solid/terms#>.
_:patch a solid:Patch;
  solid:inserts { <#me> <http://xmlns.com/foaf/0.1/knows> <https://bob.example/#me> }.
```

## Response

```http
HTTP/1.1 200 OK
```

## Headers

Servers MUST include:
```http
Accept-Patch: text/n3, application/sparql-update
```
