SLIP-60
=======

LDP Protocol
------------

`draft` `recommended` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | ✅ Yes |

This SLIP defines Linked Data Platform (LDP) protocol headers and resource types.

## Overview

LDP provides a standard way for HTTP servers to expose linked data. This SLIP covers the LDP headers, resource types, and auxiliary resource discovery.

## Resource Types

Servers indicate resource type via Link headers:

```http
HTTP/1.1 200 OK
Link: <http://www.w3.org/ns/ldp#Resource>; rel="type"
```

### For Containers

```http
Link: <http://www.w3.org/ns/ldp#Resource>; rel="type",
      <http://www.w3.org/ns/ldp#Container>; rel="type",
      <http://www.w3.org/ns/ldp#BasicContainer>; rel="type"
```

## Auxiliary Resource Discovery

### ACL Discovery

```http
Link: </alice/profile.acl>; rel="acl"
```

### Description Resource

```http
Link: </alice/profile.meta>; rel="describedby"
```

## Accept Headers

Servers advertise supported formats:

### Accept-Patch

```http
Accept-Patch: text/n3, application/sparql-update
```

### Accept-Put

```http
Accept-Put: text/turtle, application/ld+json, */*
```

### Accept-Post (Containers)

```http
Accept-Post: text/turtle, application/ld+json, */*
```

## Allow Header

```http
Allow: GET, HEAD, PUT, DELETE, PATCH, OPTIONS
```

For containers:
```http
Allow: GET, HEAD, PUT, DELETE, PATCH, OPTIONS, POST
```

## Vary Header

```http
Vary: Accept, Authorization, Origin
```

## Updates-Via (WebSocket Discovery)

```http
Updates-Via: wss://example.com/
```

## WAC-Allow Header

```http
WAC-Allow: user="read write append control", public="read"
```

## 404 Response Headers

Even non-existent resources return helpful headers:

```http
HTTP/1.1 404 Not Found
Accept-Patch: text/n3, application/sparql-update
Accept-Put: text/turtle, application/ld+json, */*
Allow: GET, HEAD, PUT, PATCH, OPTIONS
Link: </path/to/resource.acl>; rel="acl"
```

This tells clients they can create the resource with PUT or PATCH.

## Complete Example

```http
GET /alice/profile HTTP/1.1
Host: example.com
Accept: text/turtle

HTTP/1.1 200 OK
Content-Type: text/turtle
ETag: "abc123"
Link: <http://www.w3.org/ns/ldp#Resource>; rel="type", </alice/profile.acl>; rel="acl"
Accept-Patch: text/n3, application/sparql-update
Accept-Put: text/turtle, application/ld+json, */*
Allow: GET, HEAD, PUT, DELETE, PATCH, OPTIONS
Vary: Accept, Authorization, Origin
WAC-Allow: user="read write", public="read"
Updates-Via: wss://example.com/

@prefix foaf: <http://xmlns.com/foaf/0.1/>.
<#me> a foaf:Person; foaf:name "Alice".
```
