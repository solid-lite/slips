SLIP-32
=======

Data Islands
------------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | ⏳ Planned (Issue #7) |

This SLIP defines embedding RDF data directly in HTML for offline-capable Solid applications.

## Overview

Data Islands embed RDF content in HTML `<script>` tags. This enables:
- Single HTTP request (no second fetch for data)
- Offline viewing after initial load
- Static HTML export of Solid resources

## Format

```html
<!DOCTYPE html>
<html>
<head>
  <!-- Embedded RDF Data Island -->
  <script type="text/turtle" data-uri="https://example.com/alice/profile">
    @prefix foaf: <http://xmlns.com/foaf/0.1/>.
    <#me> a foaf:Person; foaf:name "Alice".
  </script>

  <!-- solidos-lite intercepts mashlib's fetcher -->
  <script src="https://cdn.jsdelivr.net/gh/solid-lite/solidos-lite/solidos-lite.js"></script>

  <!-- Standard mashlib -->
  <script src="https://unpkg.com/mashlib/dist/mashlib.min.js"></script>
</head>
<body>
  <div id="DummyUUID"></div>
</body>
</html>
```

## How It Works

1. Server embeds RDF in `<script type="text/turtle" data-uri="...">`
2. [solidos-lite](https://github.com/solid-lite/solidos-lite) patches `fetcher.load()`
3. When mashlib requests the resource, solidos-lite returns the inline data
4. No network request needed for the embedded resource

## Server Implementation

When serving RDF resources with `Accept: text/html`:

```javascript
function generateDataIslandHtml(resourceUrl, rdfContent, contentType) {
  return `<!DOCTYPE html>
<html>
<head>
  <script type="${contentType}" data-uri="${resourceUrl}">
${rdfContent}
  </script>
  <script src="https://cdn.jsdelivr.net/.../solidos-lite.js"></script>
  <script defer src="https://unpkg.com/mashlib/dist/mashlib.min.js"></script>
</head>
<body>
  <div class="TabulatorOutline" id="DummyUUID">
    <table id="outline"></table>
  </div>
</body>
</html>`;
}
```

## Benefits

| Benefit | Description |
|---------|-------------|
| **Performance** | Single request instead of two |
| **Offline** | Save HTML, view without network |
| **Static Export** | Generate static Solid sites |
| **Reduced Load** | Half the server requests |

## Considerations

- Large resources may not be suitable for embedding
- Linked resources still require network fetch
- Content must be properly escaped
