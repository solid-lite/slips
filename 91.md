SLIP-91
=======

Web Access Control (WAC)
------------------------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | ✅ Yes |

This SLIP defines Web Access Control (WAC) for fine-grained authorization.

## Overview

WAC provides granular access control using ACL (Access Control List) resources. Each resource can have an associated `.acl` file that defines who can access it and how.

## ACL Discovery

ACL resources are discovered via the `Link` header:

```http
GET /alice/profile HTTP/1.1

HTTP/1.1 200 OK
Link: </alice/profile.acl>; rel="acl"
```

## ACL Format

ACL files use Turtle format with the `acl:` vocabulary:

```turtle
@prefix acl: <http://www.w3.org/ns/auth/acl#>.
@prefix foaf: <http://xmlns.com/foaf/0.1/>.

<#owner>
    a acl:Authorization;
    acl:agent <https://alice.example/#me>;
    acl:accessTo </alice/profile>;
    acl:mode acl:Read, acl:Write, acl:Control.

<#public>
    a acl:Authorization;
    acl:agentClass foaf:Agent;
    acl:accessTo </alice/profile>;
    acl:mode acl:Read.
```

## Access Modes

| Mode | Description |
|------|-------------|
| `acl:Read` | Read resource content |
| `acl:Write` | Modify resource content |
| `acl:Append` | Add to resource (no overwrite) |
| `acl:Control` | Modify ACL |

## Agent Types

| Predicate | Matches |
|-----------|---------|
| `acl:agent <uri>` | Specific WebID or did:nostr |
| `acl:agentClass foaf:Agent` | Any authenticated user |
| `acl:agentClass acl:AuthenticatedAgent` | Any authenticated user |
| `acl:agentGroup <uri>` | Members of a group |

## did:nostr in ACLs

ACLs support Nostr identities (SLIP-21):

```turtle
<#nostrUser>
    a acl:Authorization;
    acl:agent <did:nostr:f0af1228a863772c0661ca0dd2586c58668de52ca9f71973404e7b9b1f5edc4d>;
    acl:accessTo </resource>;
    acl:mode acl:Read, acl:Write.
```

## Default ACLs

Containers can define default ACLs for child resources:

```turtle
<#default>
    a acl:Authorization;
    acl:agent <https://alice.example/#me>;
    acl:default </alice/documents/>;
    acl:mode acl:Read, acl:Write, acl:Control.
```

## WAC-Allow Header

Servers indicate permissions via `WAC-Allow`:

```http
WAC-Allow: user="read write", public="read"
```
