SLIP-31
=======

Content Negotiation
-------------------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | ✅ Yes |

This SLIP defines HTTP content negotiation for Solid Lite servers.

## Overview

Content negotiation allows clients to request resources in their preferred format. The server responds with the best matching representation.

## Accept Header

Clients specify preferred formats via the `Accept` header:

```http
GET /profile HTTP/1.1
Accept: text/turtle, application/ld+json;q=0.9, */*;q=0.1
```

## Supported Formats

| Content-Type | Format | SLIP |
|--------------|--------|------|
| `application/ld+json` | JSON-LD | SLIP-12 |
| `text/turtle` | Turtle | SLIP-30 |
| `text/html` | HTML (via Mashlib) | SLIP-44 |
| `application/n-triples` | N-Triples | - |

## Server Behavior

1. Parse `Accept` header with quality values
2. Match against available representations
3. Return best match with correct `Content-Type`
4. Include `Vary: Accept` header

## Example

Request:
```http
GET /alice/profile HTTP/1.1
Accept: text/turtle
```

Response:
```http
HTTP/1.1 200 OK
Content-Type: text/turtle
Vary: Accept

@prefix foaf: <http://xmlns.com/foaf/0.1/>.
<#me> a foaf:Person; foaf:name "Alice".
```

## HTML Representation

When `Accept: text/html` and the resource is RDF, servers implementing SLIP-44 return a Mashlib data browser view.
