SLIP-30
=======

Turtle Format
-------------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | ✅ Yes |

This SLIP defines Turtle (Terse RDF Triple Language) support for Solid Lite.

## Overview

Turtle is a compact, human-readable RDF serialization format widely used in Solid. Servers implementing this SLIP can read and write Turtle documents.

## Content Type

```
text/turtle
```

## Syntax

Turtle uses prefixes and compact triple syntax:

```turtle
@prefix foaf: <http://xmlns.com/foaf/0.1/>.
@prefix solid: <http://www.w3.org/ns/solid/terms#>.

<#me>
    a foaf:Person;
    foaf:name "Alice";
    solid:storage </>.
```

## Common Prefixes

| Prefix | Namespace |
|--------|-----------|
| `foaf:` | `http://xmlns.com/foaf/0.1/` |
| `solid:` | `http://www.w3.org/ns/solid/terms#` |
| `acl:` | `http://www.w3.org/ns/auth/acl#` |
| `ldp:` | `http://www.w3.org/ns/ldp#` |

## ACL Example

```turtle
@prefix acl: <http://www.w3.org/ns/auth/acl#>.

<#owner>
    a acl:Authorization;
    acl:agent <did:nostr:f0af1228...>;
    acl:accessTo </resource>;
    acl:mode acl:Read, acl:Write, acl:Control.
```

## Conversion

Servers SHOULD be able to convert between Turtle and JSON-LD for content negotiation (see SLIP-31).
