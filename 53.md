SLIP-53
=======

Nostr Relays
------------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | Planned |

This SLIP defines Nostr relay integration for event publishing.

## Overview

Nostr is a decentralized protocol for social networking. By integrating with Nostr relays, Solid servers can publish and subscribe to events, bridging the Solid and Nostr ecosystems.

## Event Structure

Nostr events are JSON objects:

```json
{
  "id": "abc123...",
  "pubkey": "f0af1228a863772c0661ca0dd2586c58668de52ca9f71973404e7b9b1f5edc4d",
  "created_at": 1704067200,
  "kind": 1,
  "tags": [
    ["p", "recipient-pubkey"],
    ["e", "reply-to-event-id"]
  ],
  "content": "Hello Nostr!",
  "sig": "signature..."
}
```

## Event Kinds

| Kind | Description |
|------|-------------|
| 0 | Profile metadata |
| 1 | Text note |
| 3 | Contact list |
| 4 | DM (encrypted) |
| 10002 | Relay list |
| 27235 | HTTP Auth (NIP-98) |

## Publishing Events

Solid servers can publish events to relays:

```javascript
const ws = new WebSocket('wss://relay.example.com');

ws.send(JSON.stringify([
  "EVENT",
  {
    id: "...",
    pubkey: "...",
    created_at: Math.floor(Date.now() / 1000),
    kind: 1,
    tags: [],
    content: "Published from Solid!",
    sig: "..."
  }
]));
```

## Subscribing to Events

```javascript
ws.send(JSON.stringify([
  "REQ",
  "subscription-id",
  { kinds: [1], authors: ["pubkey..."], limit: 10 }
]));
```

## Solid ↔ Nostr Bridge

### Profile Sync

```turtle
# Solid profile links to Nostr identity
<#me>
    owl:sameAs <did:nostr:f0af1228...>;
    nostr:relays ( "wss://relay1.example" "wss://relay2.example" ).
```

### Resource ↔ Event Mapping

| Solid | Nostr |
|-------|-------|
| Profile (`/profile`) | Kind 0 |
| Post | Kind 1 |
| Contact list | Kind 3 |
| Private message | Kind 4 |

## Relay Discovery

User's preferred relays from Nostr kind 10002:

```json
{
  "kind": 10002,
  "tags": [
    ["r", "wss://relay.example.com", "read"],
    ["r", "wss://relay2.example.com", "write"]
  ]
}
```

Or from Solid profile:

```turtle
<#me> nostr:relay "wss://relay.example.com".
```

## Use Cases

1. **Profile Federation** — Sync Solid profile to Nostr
2. **Activity Broadcasting** — Publish Solid activities as Nostr events
3. **Notification** — Use Nostr for real-time notifications
4. **Backup** — Mirror Solid data to Nostr relays
