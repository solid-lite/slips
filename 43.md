SLIP-43
=======

Type Index
----------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | Planned |

This SLIP defines Type Indexes for discovering resources by RDF type.

## Overview

A Type Index is a document that maps RDF types to locations where instances of that type are stored. This enables apps to discover where to find or create resources of a specific type.

## Discovery

Type indexes are discovered from the WebID profile:

```turtle
@prefix solid: <http://www.w3.org/ns/solid/terms#>.

<#me>
    solid:publicTypeIndex </settings/publicTypeIndex>;
    solid:privateTypeIndex </settings/privateTypeIndex>.
```

## Format

```turtle
@prefix solid: <http://www.w3.org/ns/solid/terms#>.
@prefix schema: <http://schema.org/>.
@prefix vcard: <http://www.w3.org/2006/vcard/ns#>.

<#contacts>
    a solid:TypeRegistration;
    solid:forClass vcard:AddressBook;
    solid:instanceContainer </contacts/>.

<#notes>
    a solid:TypeRegistration;
    solid:forClass schema:TextDigitalDocument;
    solid:instance </notes.ttl>.
```

## Type Registration

| Predicate | Description |
|-----------|-------------|
| `solid:forClass` | The RDF type being indexed |
| `solid:instance` | A specific resource of this type |
| `solid:instanceContainer` | A container holding resources of this type |

## Public vs Private

| Type Index | Visibility | Use Case |
|------------|------------|----------|
| `publicTypeIndex` | Everyone | Blog posts, public profile |
| `privateTypeIndex` | Owner only | Contacts, private notes |

## App Workflow

1. Discover user's WebID
2. Fetch profile, find type indexes
3. Fetch relevant type index
4. Look up container for desired type
5. Read/write resources there

## Example: Adding Contacts

App wants to store contacts:

```javascript
// 1. Find type index
const profile = await fetchProfile(webId);
const typeIndex = profile.publicTypeIndex;

// 2. Find AddressBook registration
const registration = await findRegistration(typeIndex, 'vcard:AddressBook');

// 3. Create contact in the registered container
const container = registration.instanceContainer;
await createResource(container + 'alice.ttl', contactData);
```

## Benefits

- Apps don't need hardcoded paths
- Users control where data lives
- Multiple apps can share data locations
- Graceful discovery of available data
