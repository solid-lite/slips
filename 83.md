SLIP-83
=======

Solid-OIDC
----------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | ✅ Yes |

This SLIP defines Solid-OIDC authentication using OpenID Connect with DPoP tokens.

## Overview

Solid-OIDC extends OpenID Connect for decentralized authentication. It allows users to authenticate with any compliant Identity Provider (IdP) and access any compliant Solid server.

## Flow

1. Client redirects user to IdP for login
2. User authenticates with IdP
3. IdP returns ID token and access token
4. Client generates DPoP (Demonstrating Proof of Possession) key
5. Client makes requests with DPoP-bound access token
6. Server verifies token and DPoP proof

## Token Request

```http
POST /token HTTP/1.1
Host: idp.example.com
Content-Type: application/x-www-form-urlencoded
DPoP: eyJ0eXAiOiJkcG9wK2p3dCIsImFsZyI6IkVTMjU2Iiw...

grant_type=authorization_code&
code=abc123&
redirect_uri=https://app.example/callback&
client_id=https://app.example/
```

## Resource Request

```http
GET /alice/profile HTTP/1.1
Host: storage.example.com
Authorization: DPoP eyJhbGciOiJFUzI1NiIsInR5cCI6IkpXVCJ9...
DPoP: eyJ0eXAiOiJkcG9wK2p3dCIsImFsZyI6IkVTMjU2Iiw...
```

## WebID Discovery

The access token contains the user's WebID in the `webid` claim:

```json
{
  "webid": "https://alice.example/#me",
  "iss": "https://idp.example.com",
  "aud": "solid",
  "iat": 1234567890,
  "exp": 1234571490
}
```

## DPoP Proof

DPoP binds tokens to a specific key pair:

```json
{
  "typ": "dpop+jwt",
  "alg": "ES256",
  "jwk": { ... }
}
{
  "htm": "GET",
  "htu": "https://storage.example.com/alice/profile",
  "iat": 1234567890
}
```

## Server Validation

Servers MUST:
1. Verify access token signature
2. Verify DPoP proof signature
3. Verify token is bound to DPoP key
4. Verify `htu` matches request URL
5. Verify `htm` matches HTTP method
6. Extract WebID from token

## Comparison with SLIP-82

| Feature | SLIP-82 (Schnorr) | SLIP-83 (Solid-OIDC) |
|---------|-------------------|----------------------|
| Identity | did:nostr | WebID |
| Key Type | secp256k1 | Various (ES256, etc.) |
| Tokens | Stateless event | OAuth access token |
| Infrastructure | None | OIDC Provider |
| Use Case | Nostr ecosystem | Traditional Solid |
