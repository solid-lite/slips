SLIP-40

Containers (LDP)
----------------

| Status | Implemented in JSS |

This SLIP defines Linked Data Platform (LDP) containers for organizing resources.

## Overview

Containers are special resources that contain other resources. They enable hierarchical organization and discovery of resources within a Solid pod.

## Container URIs

Container URIs end with a trailing slash:
```
https://example.com/alice/          # Root container
https://example.com/alice/photos/   # Sub-container
https://example.com/alice/profile   # Resource (not a container)
```

## Container Listing

GET on a container returns its contents as RDF:

```http
GET /alice/ HTTP/1.1
Accept: text/turtle
```

```turtle
@prefix ldp: <http://www.w3.org/ns/ldp#>.

<>
    a ldp:Container, ldp:BasicContainer;
    ldp:contains <profile>, <photos/>, <inbox/>.
```

## Creating Resources

POST to a container creates a new resource:

```http
POST /alice/photos/ HTTP/1.1
Content-Type: image/jpeg
Slug: vacation

[binary data]
```

Response:
```http
HTTP/1.1 201 Created
Location: /alice/photos/vacation
```

## Creating Containers

PUT with trailing slash creates a container:

```http
PUT /alice/documents/ HTTP/1.1
Content-Type: text/turtle

@prefix ldp: <http://www.w3.org/ns/ldp#>.
<> a ldp:Container.
```

## Headers

Containers include LDP headers:
```http
Link: <http://www.w3.org/ns/ldp#Container>; rel="type"
Link: <http://www.w3.org/ns/ldp#BasicContainer>; rel="type"
```
