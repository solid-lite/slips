SLIP-92
=======

Access Control Policy (ACP)
---------------------------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | Planned |

This SLIP defines Access Control Policy (ACP) for policy-based authorization.

## Overview

ACP provides a flexible, policy-based approach to authorization. Unlike WAC's resource-centric ACLs, ACP uses reusable policies that can be composed and applied to multiple resources.

## Comparison with WAC

| Aspect | WAC (SLIP-91) | ACP (SLIP-92) |
|--------|---------------|---------------|
| Model | ACL per resource | Reusable policies |
| Complexity | Simpler | More flexible |
| Discovery | `.acl` files | Access Control Resource |
| Inheritance | `acl:default` | Policy composition |

## Core Concepts

### Access Control Resource (ACR)

Every resource has an associated ACR:

```http
GET /alice/profile HTTP/1.1

HTTP/1.1 200 OK
Link: </alice/profile?ext=acr>; rel="acl"
```

### Policy

A reusable access rule:

```turtle
@prefix acp: <http://www.w3.org/ns/solid/acp#>.

</policies#readPolicy>
    a acp:Policy;
    acp:allow acp:Read;
    acp:anyOf </policies#publicMatcher>.
```

### Matcher

Defines who the policy applies to:

```turtle
</policies#publicMatcher>
    a acp:Matcher;
    acp:agent acp:PublicAgent.

</policies#ownerMatcher>
    a acp:Matcher;
    acp:agent <https://alice.example/#me>.
```

## Access Control Resource Example

```turtle
@prefix acp: <http://www.w3.org/ns/solid/acp#>.

<>
    acp:resource </alice/profile>;
    acp:accessControl <#acr>.

<#acr>
    a acp:AccessControl;
    acp:apply </policies#publicReadPolicy>, </policies#ownerFullAccess>.
```

## Policies File

```turtle
@prefix acp: <http://www.w3.org/ns/solid/acp#>.

</policies#publicReadPolicy>
    a acp:Policy;
    acp:allow acp:Read;
    acp:anyOf </policies#publicMatcher>.

</policies#ownerFullAccess>
    a acp:Policy;
    acp:allow acp:Read, acp:Write, acp:Append;
    acp:allOf </policies#ownerMatcher>.

</policies#publicMatcher>
    a acp:Matcher;
    acp:agent acp:PublicAgent.

</policies#ownerMatcher>
    a acp:Matcher;
    acp:agent <https://alice.example/#me>.
```

## Access Modes

| Mode | Description |
|------|-------------|
| `acp:Read` | Read resource content |
| `acp:Write` | Modify resource content |
| `acp:Append` | Add to resource |

## Agent Types

| Predicate | Matches |
|-----------|---------|
| `acp:agent <uri>` | Specific identity |
| `acp:agent acp:PublicAgent` | Anyone (public) |
| `acp:agent acp:AuthenticatedAgent` | Any authenticated user |
| `acp:agent acp:CreatorAgent` | Resource creator |

## did:nostr Support

ACP matchers can use did:nostr identities:

```turtle
</policies#nostrUserMatcher>
    a acp:Matcher;
    acp:agent <did:nostr:f0af1228a863772c0661ca0dd2586c58668de52ca9f71973404e7b9b1f5edc4d>.
```

## Policy Composition

Policies can require all or any matchers:

```turtle
</policies#restrictedPolicy>
    a acp:Policy;
    acp:allow acp:Read;
    acp:allOf </policies#authenticatedMatcher>, </policies#groupMatcher>.
```
