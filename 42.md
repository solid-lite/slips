SLIP-42
=======

WebSockets
----------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | ✅ Yes |

This SLIP defines WebSocket notifications for real-time updates.

## Overview

WebSockets enable clients to receive push notifications when resources change, avoiding the need for polling.

## Discovery

Servers advertise WebSocket support via the `Updates-Via` header:

```http
GET /alice/profile HTTP/1.1

HTTP/1.1 200 OK
Updates-Via: wss://example.com/
```

## Connection

Clients connect to the WebSocket endpoint:

```javascript
const ws = new WebSocket('wss://example.com/');
```

## Subscription

Subscribe to resource changes:

```javascript
ws.send('sub https://example.com/alice/inbox/');
```

## Notifications

When a resource changes, the server sends:

```
pub https://example.com/alice/inbox/
```

## Message Format

| Message | Direction | Meaning |
|---------|-----------|---------|
| `sub <uri>` | Client → Server | Subscribe to resource |
| `unsub <uri>` | Client → Server | Unsubscribe |
| `pub <uri>` | Server → Client | Resource changed |
| `ack <uri>` | Server → Client | Subscription confirmed |

## Example

```javascript
const ws = new WebSocket('wss://example.com/');

ws.onopen = () => {
  ws.send('sub https://example.com/alice/inbox/');
};

ws.onmessage = (event) => {
  if (event.data.startsWith('pub ')) {
    const uri = event.data.slice(4);
    console.log('Resource changed:', uri);
    // Fetch updated resource
  }
};
```
