SLIP-13
=======

URI Resources
-------------

`draft` `mandatory` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | ✅ Yes |

This SLIP defines URI-based resource identification for Solid Lite.

## Overview

Every resource in a Solid Lite server is identified by a URI. URIs provide stable, dereferenceable identifiers that enable linking between resources.

## Requirements

- Resources MUST be identified by URIs conforming to [RFC3986](https://tools.ietf.org/html/rfc3986)
- Servers SHOULD support IRIs per [RFC3987](https://tools.ietf.org/html/rfc3987)
- URIs MUST be stable and persistent

## URI Structure

```
https://example.com/alice/profile#me
└──────────┬──────┘└─────┬─────┘└┬┘
         origin      path    fragment
```

| Component | Purpose |
|-----------|---------|
| Origin | Server identity |
| Path | Resource location |
| Fragment | Sub-resource reference |

## Containers

Container URIs end with `/`:
```
https://example.com/alice/          # Container
https://example.com/alice/profile   # Resource
```

## Content Addressing

Resources MAY use content-based URIs:
```
https://example.com/.well-known/ni/sha-256/abc123...
```
