SLIP-10
=======

HTTP Methods
------------

`draft` `mandatory` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | ✅ Yes |

This SLIP defines the required HTTP methods for a Solid Lite server.

## Overview

A Solid Lite server is fundamentally an HTTP server that supports standard CRUD operations on resources via HTTP methods.

## Required Methods

Servers MUST support the following HTTP methods:

| Method | Purpose | Success Response |
|--------|---------|------------------|
| `GET` | Read a resource | 200 OK |
| `HEAD` | Get headers only | 200 OK |
| `OPTIONS` | Get allowed methods | 200 OK |
| `PUT` | Create or update a resource | 201 Created / 200 OK |
| `DELETE` | Remove a resource | 200 OK / 204 No Content |

## Optional Methods

Servers MAY support:

| Method | Purpose | SLIP |
|--------|---------|------|
| `POST` | Append to container | SLIP-40 |
| `PATCH` | Partial update | SLIP-33 |

## Response Codes

| Code | Meaning |
|------|---------|
| 200 | Success |
| 201 | Created |
| 204 | No Content |
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not Found |
| 405 | Method Not Allowed |
| 409 | Conflict |
| 415 | Unsupported Media Type |

## Example

```http
PUT /hello.txt HTTP/1.1
Host: example.com
Content-Type: text/plain

Hello, World!
```

Response:
```http
HTTP/1.1 201 Created
Location: /hello.txt
```

## Conformance

Servers MUST conform to:
- HTTP/1.1 Message Syntax and Routing ([RFC7230](https://tools.ietf.org/html/rfc7230))
- HTTP/1.1 Semantics and Content ([RFC7231](https://tools.ietf.org/html/rfc7231))
- HTTP/1.1 Conditional Requests ([RFC7232](https://tools.ietf.org/html/rfc7232))

Servers SHOULD conform to:
- HTTP/1.1 Caching ([RFC7234](https://tools.ietf.org/html/rfc7234))
