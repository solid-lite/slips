SLIP-12
=======

JSON-LD
-------

`draft` `mandatory` `author:melvincarvalho`

| Status | Implemented in JSS |

This SLIP defines JSON-LD as the core data format for Solid Lite.

## Overview

JSON-LD (JSON for Linking Data) provides structured, machine-readable data that can express relationships between resources. It's the default format for Solid Lite.

## Content Type

```
application/ld+json
```

Servers MUST accept and serve JSON-LD with this content type.

## Structure

JSON-LD documents use `@context` for vocabulary and `@id` for resource identity:

```json
{
  "@context": "https://www.w3.org/ns/activitystreams",
  "@id": "#me",
  "type": "Person",
  "name": "Alice"
}
```

## Common Contexts

| Context | Purpose |
|---------|---------|
| `https://www.w3.org/ns/activitystreams` | ActivityPub compatibility |
| `https://w3id.org/webid` | WebID profiles |
| `http://www.w3.org/ns/auth/acl#` | Access Control |
| `http://www.w3.org/ns/ldp#` | Linked Data Platform |

## Example Profile

```json
{
  "@context": [
    "https://www.w3.org/ns/activitystreams",
    "https://w3id.org/webid"
  ],
  "@id": "#me",
  "type": "Person",
  "name": "Alice",
  "preferredUsername": "alice",
  "storage": "/",
  "inbox": "/inbox/"
}
```
