SLIP-46
=======

SSL/TLS
-------

`draft` `recommended` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | ✅ Yes |

This SLIP defines HTTPS support for secure connections.

## Overview

Production Solid servers MUST use HTTPS to protect data in transit. This SLIP covers SSL/TLS configuration and best practices.

## Configuration

### Certificate Files

```javascript
{
  "sslKey": "/path/to/privkey.pem",
  "sslCert": "/path/to/fullchain.pem"
}
```

Or via environment:

```bash
JSS_SSL_KEY=/path/to/privkey.pem
JSS_SSL_CERT=/path/to/fullchain.pem
```

### CLI

```bash
jss --ssl-key privkey.pem --ssl-cert fullchain.pem --port 443
```

## Let's Encrypt

Free certificates via Let's Encrypt:

### HTTP-01 Challenge

```bash
# Stop server temporarily
certbot certonly --standalone -d example.com

# Certificate files
# /etc/letsencrypt/live/example.com/privkey.pem
# /etc/letsencrypt/live/example.com/fullchain.pem
```

### DNS-01 Challenge (Wildcard)

```bash
certbot certonly --manual --preferred-challenges dns \
  -d example.com -d *.example.com
```

### Auto-Renewal

```bash
# Cron job
0 0 * * * certbot renew --quiet && systemctl reload jss
```

## Server Implementation

```javascript
import https from 'https';
import fs from 'fs';

const options = {
  key: fs.readFileSync(config.sslKey),
  cert: fs.readFileSync(config.sslCert),
  // Security hardening
  minVersion: 'TLSv1.2',
  ciphers: 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256'
};

https.createServer(options, app).listen(443);
```

## HTTP → HTTPS Redirect

Production servers SHOULD redirect HTTP to HTTPS:

```javascript
// On port 80
app.use((req, res) => {
  res.redirect(301, `https://${req.hostname}${req.url}`);
});
```

## Security Headers

Additional recommended headers:

```http
Strict-Transport-Security: max-age=31536000; includeSubDomains
```

## Development Mode

For local development, use self-signed certificates:

```bash
# Generate self-signed cert
openssl req -x509 -nodes -days 365 \
  -newkey rsa:2048 \
  -keyout localhost.key \
  -out localhost.crt \
  -subj "/CN=localhost"
```

Or run without SSL on localhost:

```bash
JSS_PORT=3000 jss  # HTTP only for development
```

## Proxy Mode

Behind a reverse proxy (nginx, Caddy), terminate SSL at the proxy:

```nginx
server {
    listen 443 ssl;
    server_name example.com;

    ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto https;
    }
}
```

## TLS Best Practices

| Setting | Recommended |
|---------|-------------|
| Minimum Version | TLS 1.2 |
| Preferred | TLS 1.3 |
| HSTS | Enabled |
| Certificate Type | ECDSA preferred |
