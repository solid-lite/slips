SLIP-44
=======

Mashlib / SolidOS
-----------------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | ✅ Yes |

This SLIP defines integration with SolidOS (mashlib) for data browsing.

## Overview

SolidOS (formerly known as the Data Browser) provides a generic user interface for viewing and editing any Solid resource. When a browser requests an RDF resource with `Accept: text/html`, servers can return a mashlib-powered interface.

## How It Works

1. Client requests resource with `Accept: text/html`
2. Server detects RDF content type
3. Server returns HTML wrapper loading mashlib
4. Mashlib fetches and renders the RDF data

## HTML Wrapper

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>SolidOS</title>
  <script src="https://unpkg.com/mashlib/dist/mashlib.min.js"></script>
  <link href="https://unpkg.com/mashlib/dist/mash.css" rel="stylesheet">
</head>
<body id="PageBody">
  <header id="PageHeader"></header>
  <div class="TabulatorOutline" id="DummyUUID" role="main">
    <table id="outline"></table>
    <div id="GlobalDashboard"></div>
  </div>
  <footer id="PageFooter"></footer>
  <script>
    document.addEventListener('DOMContentLoaded', () => {
      panes.runDataBrowser();
    });
  </script>
</body>
</html>
```

## With Data Islands (SLIP-32)

For better performance, embed the RDF directly using [solidos-lite](https://github.com/solid-lite/solidos-lite):

```html
<head>
  <!-- Embedded data island -->
  <script type="text/turtle" data-uri="https://example.com/profile">
    @prefix foaf: <http://xmlns.com/foaf/0.1/>.
    <#me> a foaf:Person; foaf:name "Alice".
  </script>

  <!-- solidos-lite intercepts fetcher.load() -->
  <script src="https://cdn.jsdelivr.net/.../solidos-lite.js"></script>

  <!-- Standard mashlib -->
  <script src="https://unpkg.com/mashlib/dist/mashlib.min.js"></script>
</head>
```

Benefits:
- Single HTTP request (no second fetch)
- Offline viewing after load
- Static HTML export

## Server Implementation

```javascript
import { generateDatabrowserHtml } from './mashlib/index.js';

if (acceptsHtml && isRdfContent) {
  const html = generateDatabrowserHtml(resourceUrl);
  return reply.type('text/html').send(html);
}
```
