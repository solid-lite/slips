SLIP-52
=======

HTTP Signatures
---------------

`draft` `optional` `author:melvincarvalho`

| Status | Implemented in JSS |
|--------|-------------------|
| Draft  | Planned |

This SLIP defines HTTP Signatures for server-to-server authentication.

## Overview

HTTP Signatures allow servers to authenticate requests to other servers. This is essential for ActivityPub federation, where servers send activities on behalf of users.

## Signature Header

```http
POST /alice/inbox HTTP/1.1
Host: remote.example
Date: Sun, 06 Nov 2024 08:49:37 GMT
Digest: SHA-256=X48E9qOokqqrvdts8nOJRJN3OWDUoyWxBf7kbu9DBPE=
Signature: keyId="https://local.example/bob#main-key",
           algorithm="rsa-sha256",
           headers="(request-target) host date digest",
           signature="ODEyYjM0..."
```

## Signature Components

| Component | Description |
|-----------|-------------|
| `keyId` | URI of the public key |
| `algorithm` | Signing algorithm (rsa-sha256, hs2019) |
| `headers` | Headers included in signature |
| `signature` | Base64-encoded signature |

## Signed Headers

The following headers SHOULD be signed:

| Header | Purpose |
|--------|---------|
| `(request-target)` | Method and path |
| `host` | Target server |
| `date` | Timestamp (replay protection) |
| `digest` | Body hash |

## Key Discovery

Public keys are discovered from the Actor document:

```json
{
  "@context": "https://www.w3.org/ns/activitystreams",
  "id": "https://local.example/bob",
  "publicKey": {
    "id": "https://local.example/bob#main-key",
    "owner": "https://local.example/bob",
    "publicKeyPem": "-----BEGIN PUBLIC KEY-----\nMIIBIjANBg..."
  }
}
```

## Verification Flow

1. Receive signed request
2. Extract `keyId` from Signature header
3. Fetch Actor document at `keyId` owner
4. Extract public key
5. Verify signature against signed headers
6. Check `date` is recent (< 30 seconds)
7. Check `digest` matches body hash

## Creating Signatures

```javascript
const crypto = require('crypto');

function sign(privateKey, method, path, headers) {
  const signatureString = createSignatureString(method, path, headers);
  const signer = crypto.createSign('RSA-SHA256');
  signer.update(signatureString);
  return signer.sign(privateKey, 'base64');
}
```

## Nostr Alternative

For Nostr-native servers, use SLIP-82 (Schnorr/NIP-98) instead:

```http
Authorization: Nostr <base64-signed-event>
```

This eliminates the need for RSA keys and certificate management.
